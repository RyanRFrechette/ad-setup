# Case Study: Active Directory User Support Lab (Azure)

## Overview
Simulated help desk environment built on Azure Active Directory to practice real-world IT support scenarios. Covers user account management, access troubleshooting, and onboarding workflows.

## Environment
- **Platform:** Microsoft Azure (Azure Active Directory / Entra ID)
- **Tools:** Azure Portal, Remote Desktop Protocol (RDP), PowerShell
- **Scope:** 5 simulated support tickets across common help desk scenarios

## Problem Statement
Entry-level IT support roles require hands-on experience resolving authentication, access, and account issues in an Active Directory environment. This lab bridges that gap.

## Tickets Resolved
| # | Issue | Resolution |
|---|-------|-----------|
| 01 | User cannot log in | Verified credentials, reset account state |
| 02 | Password reset request | Performed secure password reset via Azure AD |
| 03 | Account locked out | Identified lockout source, unlocked account |
| 04 | New employee account setup | Created user, assigned groups and licenses |
| 05 | Domain / RDP access issue | Diagnosed connectivity and permission gaps |

## Key Skills Demonstrated
- Azure Active Directory user management
- Account lockout investigation and remediation
- Secure onboarding workflows
- RDP and domain access troubleshooting

## Outcome
All five tickets resolved with documented steps, simulating a production help desk workflow.
